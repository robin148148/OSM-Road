🛣️ Số Hóa Tim Đường 3-Trong-1

Google Hybrid • VN-2000 ↔ WGS84 • LRS từng 100m
Hướng dẫn: Bấm vào bản đồ để đặt Điểm đầu → Điểm giữa → Điểm cuối. Hệ thống nối thành tim đường và nội suy lý trình LRS. Kéo các điểm (drag) để chỉnh.
📌 Bám tim đường: Tải tuyến từ Tab 3 (OSM) trước → sang Tab 1 chỉ cần bấm 3 điểm (Đầu – Giữa – Cuối) → hệ thống tự bám vào tim đường thực tế và nối theo đường cong. Không giới hạn khoảng cách bấm. Dữ liệu OSM được lưu cache 7 ngày, không cần tải lại.
Nhập file kỹ thuật: Kéo-thả hoặc chọn file .kml, .geojson, .shp (zip), .dxf. Hệ thống tự nhận dạng hệ tọa độ và chuyển sang WGS84.

.kml, .geojson, .shp.zip, .dxf
VN-2000 → WGS84: Nếu file dùng VN-2000, chọn đúng tỉnh để hệ thống tự chuyển. Nếu file đã là WGS84 (GPS), chọn "Tự động" — hệ thống nhận dạng bằng cách kiểm tra khoảng tọa độ.
Tải từ OpenStreetMap: Chọn mã tuyến từ danh sách (đã xác minh) hoặc gõ mã tùy ý. Hệ thống tải hình học từ Overpass API và gộp thành tim tuyến liên tục.
⚠️ Nguồn danh sách (từ web, không từ dữ liệu user): Cao tốc 46 tuyến (CT.01-CT.46). Quốc lộ 152 tuyến từ Wikipedia. Bỏ qua ĐT — đường tỉnh do từng tỉnh quản lý, không thuộc hệ thống toàn quốc. Khu vực tỉnh: 34 tỉnh/thành sau sáp nhập 01/07/2025.
⚠️ Giới hạn OSM: Dữ liệu OSM do cộng đồng đóng góp, không phải dữ liệu chính thức. Một số tuyến có thể thiếu, đứt đoạn hoặc chưa cập nhật. Với công việc chính thức, dùng Tab 1 (bấm tay) hoặc Tab 2 (file kỹ thuật).
Cache lưu 7 ngày trong trình duyệt, tải lại không cần gọi Overpass.
